# Tutubi: A BIR EIS-compliant Business Management System
Tutubi is a business management system created as a capstone project for Don Bosco Technical College for our beneficiary: Barangka Meat Shop. It is a cloud-based web application that uses the Firebase backend-as-a-service as its backend, and it interfaces with the Buraeu of Internal Revenue's (BIR) Electronic Invoicing System (EIS) for its greater accuracy, faster processing, and easier auditing process compared to paper-based invoicing. It also features a blockchain-powered ledger system that offers the business extra security and tamper-proofing for its precious records.
